# Security

Zhiyin keeps people's YouTube access tokens (encrypted at rest), session cookies and listening history. If you find
a way to read or change another listener's data, sign in as someone else, or get at the tokens, please report it
privately through [GitHub's private vulnerability reporting](https://github.com/billpwchan/zhiyin/security/advisories/new)
rather than in a public issue. I'll reply within a few days.
